# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep feedback about the work, and do not harass anyone. This applies in issues, pull requests and any other project space.

To report unacceptable behaviour, open a [private security advisory](https://github.com/hsiddhu2/reseat/security/advisories/new) marked as a conduct report, or contact the maintainer through their GitHub profile. Reports are handled in confidence.
